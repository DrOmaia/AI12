Skill Builder

A skill is a folder containing a SKILL.md file: a short header (name and description) followed by instructions in Markdown. Fill in the form to generate one. Nothing you type leaves your browser.

Before you download
The folder name must be exactly the same as the skill name. If your skill is called feedback-drafter, save the file as feedback-drafter/SKILL.md. Skill support differs by tool and plan: check your tool's help pages. If your tool has no skills, use the "Custom instructions" view and paste the text instead.

1. Describe your skill

Lowercase letters, digits and single hyphens. No hyphen at the start or end, no double hyphens, 64 characters at most. Example: feedback-drafter
One or two sentences. Say what the skill does and when to use it (for example "Use when I ask for..."). The tool reads this to decide when to load the skill.
Why this skill exists and who uses its output.
One step per line. Numbers are added for you.
What the result must look like: sections, length, tone.
What the skill must never do, and when it must stop and ask you.
One short input and the output you would accept.

2. Your skill

After you generate it, check: would the description alone tell the tool when to use this skill? Does the boundaries section include your red lines? Test it on a real task and review the output before use.
